# dailen-portfolio 项目简报

## 1. 项目目标

开发一个用于自我介绍、实习与求职的个人作品集网站，最终部署到 `dailen.top`。

网站本身要成为体现开发能力的作品，视觉目标为：**酷炫、精细、有探索感**。

核心理念（"Dailen 的互动作品展馆"）：访客不是滚动浏览页面，而是进入一个可探索的 3D 空间，通过空间导航、镜头移动、开门进入场景等方式浏览作品。

## 2. 内容结构

网站分为五个功能区：

1. **入口（Entry）**：名字、个人定位、进入体验的引导。
2. **关于我（About）**：专业背景、个人介绍、发展方向。
3. **项目展厅（Projects Gallery）**：项目封面、简介、技术栈、本人工作、在线演示与源码入口。
4. **经历与实验（Experience & Labs）**：学习实践、比赛经历、后续交互练习。
5. **联系区（Contact）**：邮箱、代码平台、简历入口。

约束：

- 始终保留**直接访问作品和联系方式**的导航（不依赖 3D 交互即可触达核心内容）。
- 手机端和 WebGL 不可用时，仍能浏览核心内容（提供无 WebGL 降级方案 / 语义化回退）。

## 3. 初步概念：互动作品展馆

- **入口** → 打开作品区（开门进入场景）→ 查看具体项目 → 跳转在线演示与源码。
- 第一阶段先用**简单几何体与占位素材**验证镜头与交互，再制作统一风格的素材与精细动效。

## 4. 第一阶段实现范围（最小三维体验）

### 重点研究方向

1. 空间导航（空间内移动而非传统滚动）
2. 镜头移动（多输入相机：滚动、鼠标、移动端陀螺仪）
3. 开门进入场景（走向门并穿过以切换场景）
4. 作品浏览与加载策略（自适应设备分层、异步着色器编译、纹理加载策略）

## 6. 技术方向

- **React + TypeScript + Vite**
- **Three.js / React Three Fiber（R3F）+ drei**
- **GSAP** 负责镜头与交互动画
- **npm** 管理依赖

第一版按**静态前端**设计：项目内容集中配置（数据与界面分离），方便后续增加作品。
