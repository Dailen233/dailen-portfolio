# dailen-portfolio 开发计划

> 分阶段任务，每阶段给出**可观察的验收标准**。当前已完成阶段 0–2（脚手架 + 最小三维体验）。

## 阶段 0：项目初始化与启动规划（当前已完成）

- 检查仓库与环境（Node / npm / Git）。
- 核实依赖的 Node 要求与版本兼容性。
- 创建 `docs/project-brief.md`、`docs/development-plan.md`，更新 `README.md`。

**验收标准**：

- [x] 仓库、分支、工作区状态已确认，已有内容未受影响。
- [x] 环境版本已记录，阻塞项与修复步骤已明确。
- [x] 两份文档与 README 已就位，待填写项已标注。

## 阶段 1：脚手架搭建（已完成）

- 用 Vite 初始化 React + TypeScript 项目。
- 引入 Three.js / R3F / drei / GSAP 依赖并锁定版本。
- 建立内容集中配置目录（项目数据与界面分离）。

**验收标准**：

- [x] `npm install` 成功，无 peer 依赖冲突。
- [x] `npm run dev` 能启动开发服务器并渲染一个空页面。
- [x] 内容数据以独立配置文件（`src/content/`）集中管理，页面不硬编码项目内容。

## 阶段 2：最小三维体验（第一里程碑，已实现）

- 用简单几何体搭建"入口 → 作品区"的占位场景。
- 实现镜头移动与开门进入作品区的交互（占位动画）。
- 在作品区放置"双语电子书"项目卡片（占位素材）。
- 项目卡片可跳转到在线演示与源码入口。

**验收标准**：

- [x] 打开页面能看到三维场景并能进入作品区。
- [x] 镜头移动、开门交互可用（用占位几何体验证）。
- [x] 点击"双语电子书"能跳转至 `http://ebook.dailen.top/index.html`（源码入口暂为"待填写"占位）。
- [x] 在无 WebGL / 移动端降级路径下，仍能通过导航直达作品与联系方式。

> 注：构建通过但**浏览器交互尚未实机验证**（进入、开门、返回、项目链接、窄屏、简洁模式），标记为「待用户验证」。

## 阶段 3：统一风格素材与精细动效

- 制作统一视觉风格的素材（纹理 / 几何 / 文案）。
- 用 GSAP 细化镜头路径、开门、场景切换等动效。
- 完善空间导航与场景切换的体验打磨。

**验收标准**：

- [ ] 素材风格统一，视觉达到"酷炫、精细、有探索感"。
- [ ] 动效流畅（目标 60fps），镜头与开门过渡自然。
- [ ] 核心交互在桌面端体验稳定。

## 阶段 4：内容与降级完善

- 补齐"关于我 / 项目展厅 / 经历与实验 / 联系区"内容。
- 接入真实个人资料、项目成果、邮箱、简历入口。
- 完善无 WebGL 降级与移动端适配、SEO 语义化回退。

**验收标准**：

- [ ] 五个功能区内容齐全且准确（项目状态按实际填写）。
- [ ] 手机端与无 WebGL 环境可浏览核心内容。
- [ ] 直接访问作品与联系方式的导航始终可用。

## 阶段 5：构建、部署与收尾

- 生产构建与性能优化（加载策略、体积、缓存）。
- 部署到 `dailen.top`。
- 记录引用代码的许可与归属。

**验收标准**：

- [ ] `npm run build` 成功，生产包可正常预览。
- [ ] 站点在 `dailen.top` 可访问，核心流程端到端可用。
- [ ] 引用代码的许可与归属说明完整。

## 下一轮建议的最小任务

进入阶段 3（统一风格素材与精细动效）前，先完成阶段 2 的浏览器实机验收：

1. 手动验证交互流程：进入、开门、返回、项目演示链接（新标签）、窄屏、简洁模式。
2. 若交互正常，再着手阶段 3：统一视觉风格、细化镜头与开门动效。

## 空间导航模块顺序（进行中）

1. **画廊房间探索**（已验收）：房间内滚轮/拖动/滑动连续浏览两展墙画框，点选项目、聚焦、关闭恢复。
   - 功能已通过手动录屏验收，视觉细节留待统一素材阶段打磨。
2. **有限走廊滚动导航**（本轮修复验收中）：桌面滚轮 / 手机上下滑动沿走廊前进后退，前后边界受限；从任意位置进房间并返回位置恢复。
   - 已修复：输入→位移换算过大（一格滚轮/小幅滑动掠过整段走廊）、远端无封底导致纸色空白。补纸面封底墙 + 钳制朝向目标 + 限制速度/漂移。
3. **循环走廊**（未开始）：走廊首尾衔接为可循环的空间，形成连续漫游。

> 注：以上为空间导航的独立子模块，均沿用 CameraRig 单一相机写入者与现有位置状态机，不新增第二个相机控制者、不新增房间。
